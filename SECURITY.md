# Security policy

## Supported versions

Security fixes are released for the latest minor version of callscope.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub: go to the repository's **Security** tab and click **Report a vulnerability** ([direct link](https://github.com/Vigneshselvaraj1811/callscope/security/advisories/new)).

Include:

- what the problem is and its impact (for example, a secret printed despite masking),
- the smallest code that reproduces it,
- the callscope, Python and library versions.

You'll get a reply within 7 days. Once a fix is released, you'll be credited in the changelog unless you'd rather not be.
